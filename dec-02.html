Level 1: Tenths Place

The Space Between

Decimals live in the gap between whole numbers.

If we cut the space between 0 and 1 into ten equal pieces, each gap represents exactly 0,1 (one tenth).

The Zooming Number Line

What if a number is between 0,1 and 0,2?

We can take a magnifying glass and "zoom in" on the space between 0,1 and 0,2.

We slice it into ten new pieces to create the Hundredths (0,11 to 0,19). Because 0,1 is the same as 0,10!

Infinite Decimals
