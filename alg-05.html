The Reverse Flow Trap!

Two mistakes break a Reverse Flow Diagram:

❌ Mistake 1 (Keeping Forward Signs): Doing 14 + 2 or 14 × 3 when moving backwards!
❌ Mistake 2 (Wrong Reverse Order): Dividing 14 ÷ 3 first before undoing + 2!
✓ Correct Rule: Start at the Output, undo the LAST box first (− 2), then undo the FIRST box (÷ 3).

Flip the Spider Diagram to Inverse Mode first, then calculate the Middle Value and Input x.
